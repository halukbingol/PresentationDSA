Git -- six Beamer decks
=======================

decks/git-1-concepts    git-concepts.tex    why version control, installing (Windows, macOS), commits and hashes,
                                            working tree / staging area / repository, objects, branches and HEAD,
                                            fast-forward and three-way merge, remotes, team work
decks/git-2-examples    git-examples.tex    real sessions: init, diff, .gitignore, branch, merge, conflicts,
                                            undo (restore, revert), stash, tags, a remote, history, rebase
decks/git-3-freshman    git-freshman.tex    configuring Git, the first repository step by step, a Java project
                                            with .gitignore, quick fixes, common errors with their real messages
decks/git-4-sophomore   git-sophomore.tex   two people and a server: feature branches, rejected pushes,
                                            pull --rebase, a Java conflict, comparing branches, squash,
                                            shortlog, .gitignore patterns, releases
decks/git-5-junior      git-junior.tex      the object database, refs, reset --soft/--mixed/--hard, reflog,
                                            detached HEAD, fixup + autosquash, cherry-pick, bisect run,
                                            -S/-G/-L searches, hooks
decks/git-6-senior      git-senior.tex      plumbing (a commit by hand), SHA-256 repositories, packfiles,
                                            partial clone + sparse checkout, worktrees, merge strategies,
                                            rerere, range-diff, secrets in history, signed commits,
                                            config scopes and includeIf, branching models, CODEOWNERS, CI,
                                            git describe and semantic versions

hblib/                  the libraries and template from hblib.zip; hblibDatastructures.sty has new
                        TikZ styles: trees (htree, hnode, hsquare, hhot, hdone, hleaf, horder=k) and
                        commit graphs (hcommit, hbranch, hheadref, htag, hparent),
                        version line v20261015T2000; older decks are not affected

Building a deck (Windows: Command Prompt; macOS: Terminal)
-----------------------------------------------------------
  cd decks/git-3-freshman
  pdflatex git-freshman.tex       (twice, for i/N and the outline)

Terminal sessions and their outputs
-----------------------------------
Every terminal output on the slides is REAL (Git 2.43, Linux):
  codeoutput/<Name>.sh       a terminal session, run in a copy of codeoutput/<Name>/;
                             lines starting with "#@ " are silent set-up
  codeoutput/<Name>.txt      what it printed, regenerated by:   bash run_examples.sh  [Name.sh]
                             (macOS: Terminal; Windows: Git Bash)
The sessions are reproducible: each one uses a fresh empty HOME, the author "Ayse Yilmaz
<ayse@example.com>", branch name main and fixed commit dates, so the same hashes appear on
every run. Temporary folders are shown as ~/project.
Not run (marked "Not run here" on the slides): git filter-repo and ssh-keygen (not installed),
GitHub Actions (runs on GitHub's servers).
