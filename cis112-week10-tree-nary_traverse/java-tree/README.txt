Trees, Binary Trees, N-ary Trees and Traversal in Java -- six Beamer decks
==========================================================================

decks/tree-1-concepts    tree-concepts.tex    terms, binary trees (full/complete/perfect), N-ary trees,
                                              representations (links, arrays, first child/next sibling),
                                              pre/in/post/level order, Euler tour, which traversal for what
decks/tree-2-examples    tree-examples.tex    real programs: Node, four traversals, size/height/leaves,
                                              expression trees, array trees, N-ary trees, a folder tree, BST
decks/tree-3-freshman    tree-freshman.tex    building a tree by hand, thinking recursively, tracing traversals,
                                              common mistakes with their real error messages
decks/tree-4-sophomore   tree-sophomore.tex   generic Node<T>, visitors (lambdas), iterative traversals,
                                              an inorder iterator, BST insert/search/delete, checking a BST,
                                              rebuilding and serializing trees, generic N-ary trees
decks/tree-5-junior      tree-junior.tex      height and balance, AVL trees (rotations, 1.44 log n proof),
                                              timings, deep trees and Morris traversal, tries, heaps
decks/tree-6-senior      tree-senior.tex      sealed records and pattern matching, symbolic differentiation,
                                              persistent trees (path copying), fork/join, NavigableMap,
                                              HashMap tree bins, the DOM and XML security, B-trees

hblib/                   the libraries and template from hblib.zip; hblibDatastructures.sty has new
                         TikZ styles for trees (htree, hnode, hsquare, hhot, hdone, hleaf, horder=k),
                         version line v20261015T1700; older decks are not affected

Building a deck (Windows: Command Prompt; macOS: Terminal)
-----------------------------------------------------------
  cd decks/tree-3-freshman
  pdflatex tree-freshman.tex       (twice, for i/N and the outline)

Programs and their outputs
--------------------------
Every output on the slides is REAL (JDK 21, Linux):
  codeoutput/<Name>.java     a program; classes without main() (Node, Bst, Avl, ...) are only compiled
  codeoutput/<Name>.in       its keyboard input, .args its arguments, .jvmargs its JVM options (optional)
  codeoutput/<Name>.sh       a terminal session, run in a copy of codeoutput/<Name>/
  codeoutput/<Name>.txt      what it printed, regenerated by:   bash run_examples.sh  [Name.java]
                             (macOS: Terminal; Windows: Git Bash)
Classes are compiled with javac -g, so NullPointerException messages name the variables.
Timings (AVL vs BST, fork/join) change from run to run.
