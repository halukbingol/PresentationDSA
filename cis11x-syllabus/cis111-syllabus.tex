\section{Catalog Definition}

Software development basics such as 
documentation, 
naming conventions, 
version control, 
debugging, 
refactoring, 
object-oriented thinking, 
integrated development environment. 

Programming in Java including 
constants, 
variables, 
expressions and operations, 
loops, 
conditional branching, 
methods, 
exception handling, 
I/O, 
arrays, 
String object, 
objects, 
inheritance, 
polymorphism.
