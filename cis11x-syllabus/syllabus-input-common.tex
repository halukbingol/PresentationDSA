Note that 

\begin{itemize}
	
	\item 
	\textbf{Curve.}
	Letter grading is based on curve.
	
	\item 
	All the sections have a common exam. 

	\item 
	\textbf{LabPlus.} 
	If you complete the Goal during the lab, you get one LabPlus. 
	If you complete the Challenge, too, you get one more LabPlus. 
	There is only one demo and explanation allowed for Goal or Challenge. 
	Enough number of LabPluses move your letter grade up by one 
	if your grade is DD or up and close to the boundary. 
		
	\item 
	\textbf{Cafer.} 
	Grading is done by Java Auto Grader, called Cafer. 
	It grades your submission to YULearn at the end of the exam. 
	Make sure that your submission compiles without any error. 
	Cafer grades non-compiling code as 0.
	
\end{itemize}

\section{Attendance}

Attendance is mandatory. 
\begin{itemize}
	
	\item 
	If you are late more than 30 minutes, then you are considered absent.
	
	\item 
	\textbf{FA.}
	Maximum absence before FA is 6.	 
	If you are absent more than 6 labs or lectures, 
	that is, 12 hours in total, 
	than you will automatically fail the course with letter grade of FA.
	
	\item 	
	\textbf{QR code.}
	A7 QR code is used for attendance. 
	It is your responsibility to check 
	if QR worked properly.
	
\end{itemize}
