# Procedure for creating LaTeX presentation on a topic

1. zip `hblib` directory

1. upload `hblib.zip` to AI

1. use the following prompt
	
	
	Consider the libraries
	 
	- `hblibCodeoutput.sty`,
	- `hblibDatastructures.sty`,
	- `hblibPresentation.sty`
	
	and template
	
	- `Template/hblibTemplate.tex`
	
	in `hblib.zip`.
	
	Provide
	
		- {topic}-0-concepts
		- {topic}-1-freshman
		- {topic}-2-sophomore
		- {topic}-3-junior
		- {topic}-4-senior
		- {topic}-5-examples

	level 6 LaTeX presentations on the topic 
	applying the rules given in 
	`0hb-Rules-of-LaTeX-Beamer-v2.md`
	
	where {topic} is 
	
	"eclipse".
