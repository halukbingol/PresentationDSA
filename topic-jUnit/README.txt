Building a deck (Windows: Command Prompt; macOS: Terminal)
-----------------------------------------------------------
  cd junit-1-freshman
  pdflatex junit-freshman.tex       (twice, for i/N and the outline)

Programs and their outputs
--------------------------
Every output on the slides is REAL (JDK 21, Linux), regenerated by:  bash run_examples.sh
  codeoutput/<Name>.sh     a terminal session, run in a copy of codeoutput/<Name>/;
                           lines starting with "#@ " are silent set-up
  codeoutput/<Name>.txt    what it printed
Versions used: JUnit Jupiter 5.10 / Platform 1.9 (console launcher, "execute" command),
JUnit 4.13.2 for the Vintage example, Mockito 2.23, JaCoCo 0.8.11.
The current release is JUnit 6.1.3; every API used on the slides is the same in JUnit 6.
  - "junit" in the sessions is short for
        java -jar junit-platform-console-standalone.jar execute --disable-banner
             --disable-ansi-colors --details-theme=ascii --include-engine=junit-jupiter
    and the line "Test run finished after N ms" (a time) is removed.
  - Times (parallel execution) and identity hashes such as [I@19e4653c change from run to run.
  - Not run here (marked on the slides): Maven, Gradle, PIT, OpenRewrite (they need the internet).
