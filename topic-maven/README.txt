Maven for Java -- six Beamer decks
==================================

maven-0-concepts    maven-concepts.tex    what a build is, a short history (make, Ant, Maven, Gradle), convention over
                                          configuration, coordinates and repository paths, local and remote
                                          repositories, the dependency graph and scopes, the lifecycle (algorithm),
                                          the POM (inheritance, aggregation), the same commands on Windows and macOS
maven-1-freshman    maven-freshman.tex    why a build tool, installing (Windows, macOS), mvn -v, the standard layout,
                                          pom.xml, compile / test / package / clean, reading the log, java -jar,
                                          six real failures (compile error, failing test, no POM, wrong phase,
                                          broken XML, missing JUnit), Maven in the IDE
maven-2-sophomore   maven-sophomore.tex   lifecycles, phases and goals, calling goals directly, dependencies and
                                          dependency:tree, the local repository, scopes and class paths, dependency
                                          mistakes, resources and filtering, exec:java, a manifest, a shaded jar,
                                          choosing and skipping tests
maven-3-junior      maven-junior.tex      multi-module projects (parent, modules, reactor, -pl -am), install, local /
                                          remote / mirror and settings.xml, source jars, profiles (by hand and by OS),
                                          version conflicts (NoSuchMethodError, dependencyManagement, enforcer
                                          dependencyConvergence), enforcer rules, dependency:analyze, the wrapper
maven-4-senior      maven-senior.tex      the effective POM, dependency mediation (algorithm), nearest wins, scopes
                                          along the path, version ranges, releases and snapshots, version order,
                                          BOMs, reproducible builds (outputTimestamp, sha256), writing a plugin
                                          (Mojo), deploy, Maven Central (Central Portal), CI with GitHub Actions,
                                          supply-chain security, Maven 4, Maven vs Gradle, projects
maven-5-examples    maven-examples.tex    the concepts as real sessions: a build by hand, the layout before and after,
                                          coordinates as paths, offline mode, transitive dependencies, class paths per
                                          scope, phases and goals, a failure that stops the build, inheritance

offline-settings.xml   see below
../hblib/              shared by all topics (home/hblib); no library change for these decks

Building a deck (Windows: Command Prompt; macOS: Terminal)
-----------------------------------------------------------
  cd maven-1-freshman
  pdflatex maven-freshman.tex       (twice, for i/N and the outline)

Sessions and their outputs
--------------------------
Every output on the slides is REAL (Maven 3.9.11, JDK 21, Linux), regenerated by:  bash run_examples.sh
  codeoutput/<Name>.sh     a terminal session, run in a copy of codeoutput/<Name>/ (the project files);
                           lines starting with "#@ " are silent set-up
  codeoutput/<Name>.txt    what it printed
  - "mvn" in the sessions is   mvn -B -ntp   (batch mode, no download progress); the home folder is shown as ~
    and the temporary project folder as ~/project.
  - No internet access here: when ../offline-settings.xml exists, the sessions add  -s ../offline-settings.xml.
    It replaces Maven Central by /opt/maven-offline-repo, a local repository made from the Debian packages of
    the plugins (versions as in Debian: compiler 3.10.1, surefire 2.22.3, jar 3.3.0, resources 3.3.0,
    install 3.1.1, deploy 3.1.1, dependency 3.5.0, shade 3.4.1, enforcer 3.1.0, exec 3.1.0, plugin 3.7.1;
    JUnit Jupiter 5.10.1 with Platform 1.9.1; commons-lang3 3.14.0). The POMs pin these plugin versions.
    With internet access delete or ignore offline-settings.xml: plain mvn uses Maven Central, and newer
    plugin versions can be used.
  - Times ("Total time", "Time elapsed", reactor times), dates ("Finished at") and the jar hashes of the
    non-reproducible build change from run to run.
  - Current versions (October 2026): Maven 3.10.0 (September 2026) is the current release; Maven 4 is at
    4.0.0-rc-7 (September 2026, needs Java 17). The commands on the slides are the same in 3.10.
  - Not run here (marked on the slides): installing Maven on Windows / macOS, the Maven Wrapper
    (wrapper:wrapper, mvnw), help:effective-pom, publishing to Maven Central, GitHub Actions, Maven 4.
