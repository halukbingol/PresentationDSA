Regular Expressions in Java -- six Beamer decks
===============================================

regex-0-concepts    regex-concepts.tex    a pattern as a set of strings, the four uses (validate, search, extract,
                                          transform), building blocks (classes, quantifiers, anchors, groups,
                                          alternation), Pattern and Matcher, the two languages in one line (\\),
                                          finite automata and backtracking (algorithm), greedy and lazy, grep,
                                          Windows and macOS tools, limits, the road through the levels
regex-1-freshman    regex-freshman.tex    String.matches, classes and quantifiers, phone numbers, the backslash,
                                          split, replaceAll, error messages (PatternSyntaxException, javac
                                          "illegal escape character", $ in a replacement), validating input
regex-2-sophomore   regex-sophomore.tex   Pattern and Matcher, find in a loop, groups and named groups, flags
                                          (COMMENTS, MULTILINE, DOTALL), parsing a log, replacing with a function,
                                          look-ahead (password policy), greedy and lazy, compile once, JUnit tests
regex-3-junior      regex-junior.tex      Unicode and Turkish letters (\p{L}, UNICODE_CASE, i/ı/I/İ), graphemes and
                                          NFC, back-references, look-around, possessive and atomic groups, newer
                                          APIs (results, namedGroups, splitWithDelimiters), Scanner, speed
regex-4-senior      regex-senior.tex      regular languages and their limits, a DFA, backtracking and NFA
                                          simulation (algorithms), ReDoS with real timings, Java's memoization and
                                          where it stops, StackOverflowError, a deadline in charAt, RE2/J,
                                          regex injection (Pattern.quote, Matcher.quoteReplacement), when not to
                                          use a regex, projects
regex-5-examples    regex-examples.tex    the concepts as real programs: a match table, anchors, groups, escapes,
                                          word counts, greedy/lazy, a DFA as a table, a 35-line backtracking
                                          matcher with its trace, counting steps, validation, form vs meaning

../hblib/   shared by all topics (home/hblib); no library change for these decks

Building a deck (Windows: Command Prompt; macOS: Terminal)
-----------------------------------------------------------
  cd regex-1-freshman
  pdflatex regex-freshman.tex       (twice, for i/N and the outline)

Programs and their outputs
--------------------------
Every output on the slides is REAL (JDK 21, Linux), regenerated by:  bash run_examples.sh
  codeoutput/<Name>.java   a program; output -> codeoutput/<Name>.txt
                           (<Name>.in: keyboard input, <Name>.args: arguments)
  codeoutput/<Name>.sh     a terminal session, run in a copy of codeoutput/<Name>/;
                           lines starting with "#@ " are silent set-up
  codeoutput/<Name>.txt    what it printed
  - Times change from run to run and machine to machine (junior: Speed; senior: Csv, Memo, Re2);
    the growth and the ratios stay.
  - RE2/J 1.7 (com.google.re2j:re2j, the latest on Maven Central) came from Debian's libre2j-java;
    the session copies re2j-1.7.jar into the project folder.
  - JUnit sessions (sophomore): JUnit Platform console launcher 1.9 ("execute" command).
  - Not run here (marked on the slides): Maven, findstr and PowerShell on Windows.
